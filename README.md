# 煤矸石智能匹配平台 · 双端口 Demo（2026-11）

一张图 / 一张化验单进去，得到 **煤矸石资源化路线 + 八工序 + 参数 + 风险拦截 + 相似标杆案例**。

本版在 2026-10 的三步式视觉 Demo 上做了三件事：

1. **用 2026-11 新库重训四氧化物模型**：635 条真实记录中筛选 328 条 / 299 个来源组，1 个目标持平、3 个目标提升；
2. **重写 R01~R12 知识库**：按总表 12 大标准路线 + 八工序 + 环保红线，增加含硫/高钙/重金属/放射性等一票否决规则；
3. **新增端口一“化验单精准匹配”**：直接填 XRF / 工业分析 / XRD / 工艺要求，输出可执行方案；与端口二共用同一套 R01~R12 知识库。

---

## 1. 两个端口

### 端口二 · 视觉粗筛（http://127.0.0.1:7880/）

- YOLOv8s 识别煤块 / 矸石 / 低置信度其他杂石；
- 每块矸石独立生成输入卡，带入第一步 CV 读到的 D/L/G/T/S；
- 输入六项现场指标 + 可选工业分析/XRD，逐石预测 SiO₂ / Al₂O₃ / Fe₂O₃ / CaO；
- 预测后弹出逐石误差（`|预测−真实|/真实`），并显示模型整体 R²；
- 用 R01~R12 知识库逐石推荐，先跑风险门控，再按成分/比值/物性排序。

### 端口一 · 实验报告精准匹配（http://127.0.0.1:7880/precision）

1. **图片识别**：支持 JPG/JPEG/PNG/BMP/WEBP/TIF/TIFF 上传；YOLO 标出煤块/矸石并编号，只对矸石生成实验报告；
2. **逐石必填表单**：一块一块填写，测试阶段自动带入库内默认值；XRF、工业分析、XRD、pH/重金属/放射性等全部必填（无 XRD 填 0），缺项会阻止生成方案；
3. **逐石处理方案**：按图片编号顺序输出 R01~R12 路线、SVG 八工序数据流图、参数、路线要求和风险控制；**不显示“为什么选它”**；
4. **双击方案**：打开本块实验指标（XRF/工业/XRD/环境）核对；
5. **思考动画**：生成时显示“AI 正在根据知识库深度学习”、转圈和 2 秒进度条；
6. **模型配置**：右上角「模型配置」可填智谱 API Key；默认免费 `glm-4.5-flash`，未配置则离线知识库。

## 2. 四氧化物模型：新库重训结果

### 2.1 数据筛选

新库 `data/新数据库_635.xlsx`：

- 635 条真实记录 / 528 个来源组；
- 四目标完整 443 条；
- 用于建模的 **328 条 / 299 组**，筛选条件：
  - 有明确 R01~R12 利用路线；
  - 排除 `D级_多样品统计均值（禁入单样模型）`；
  - SiO₂ / Al₂O₃ / Fe₂O₃ / CaO 四目标齐全；
  - 全成分加和 85~105 wt%；
  - 常规煤矸石域：SiO₂ 20~75、Al₂O₃ 5~45、Fe₂O₃ 0.1~25、CaO 0~20 wt%。

> 这是“端口二适用域”的定义，不是声称高钙/高铁矸石不存在；超出该域的输入会在页面上标“域外”，只作方向参考。

### 2.2 指标（按来源组 5 折 × 种子 42/7/2024，pooled OOF）

| 目标 | 2026-10 旧模型 R² | **2026-11 v2 R²** | 变化 | MAE | 训练量 |
|---|---:|---:|---:|---:|---:|
| SiO₂ | 0.7272 | **0.7196** | −0.008（基本持平） | 3.45 | 328 / 299 组 |
| Al₂O₃ | 0.2719 | **0.6410** | **+0.369** | 3.29 | 328 / 299 组 |
| Fe₂O₃ | 0.3380 | **0.4298** | **+0.092** | 1.77 | 328 / 299 组 |
| CaO | 0.1196 | **0.3535** | **+0.234** | 1.29 | 328 / 299 组 |

- 模型：RidgeCV + XGBoost 集成；权重按 OOF 选择（不是拍脑袋）；
- 特征：LOI、K₂O、MgO、Na₂O、TiO₂、SO₃、灰分、挥发分、固定碳、全硫、发热量、高岭石、石英、伊利石、绿泥石、方解石、黄铁矿、P₂O₅、`_den`；类别特征：省/市/煤田/样品状态/颜色/岩相；
- **SiO₂ 没有提升**，与旧交付版基本持平；Al₂O₃ / Fe₂O₃ / CaO 提升明显。报告时如实写“3/4 提升，SiO₂ 持平”，不要把小差异说成显著提升。
- **CaO 仍然偏弱（0.354）**：它受碳酸盐/石膏/pH 影响大，页面会提示结合区间和补检，不把它包装成高可信。
- 完整方法与复现见 **[模型重训报告_2026-11.md](模型重训报告_2026-11.md)**。

### 2.3 为什么不用旧模型

旧 SiO₂ 模型迁移到新库 328 条上 R² 仅约 0.255，说明旧模型吃的是旧 261 条的分布，不能用它来“保住 0.727”。本版统一用新库重训，避免新旧口径混用。

## 3. 知识库：R01~R12 + 风险门控

`kb/process_kb_v3.json`：12 条标准组合路线，每条包含：

- 成分窗口 `conditions`（SiO₂/Al₂O₃/Fe₂O₃/CaO/MgO/SO₃/LOI/St/Qnet 等）；
- 特征比值 `ratios`（Si/Al、Al/Si、Fe/Al、Ca/Si、LOI/灰分、FLUX 等）；
- 定义性门控 `gate`；
- 主导特征 `regime`；
- 物性偏好 `physical`（D/L/G/T/S 只做小权重排序）；
- **阶段 4**：八工序链 `process_chain`、关键参数 `parameters`、产品、机理；
- **阶段 5**：风险门控、合规/环保红线、建议补检、路线硬性要求、对标标准。

`risk_rules` 8 条：

| 规则 | 触发 | 处理 |
|---|---|---|
| 高硫强酸性 | St > 1.5% | R01/R10 一票否决；R02/R04/R06/R11/R12 降权并要求脱硫/中和；补检 pH/重金属 |
| 石灰爆裂 | CaO > 2.5% | 未细磨/消解时 R06 拦截，转 R02/R11 或先磨细 <0.5 mm |
| 高热值 | Qnet ≥ 6.27 MJ/kg | R12 加权；非能源路线受 Qnet 窗口约束 |
| 低热值 | Qnet < 1.0 MJ/kg | 禁止 R12 |
| SO₃ 超限 | SO₃ > 3.5% | R02 水泥混合材拦截/复核 |
| 酸性浸出 | pH < 4 | R01/R10 拦截，需中和/阻隔 |
| 重金属 | II 类需控/超标危废 | R01/R10 拦截，稳定化/固化 |
| 放射性 | IRa>1.0/超标 | 建筑建材路线拦截，封闭回填/专业处置 |

> 这些是**工程经验/标准方向性阈值**，不是强制标准；落地必须小试/中试 + 重金属、放射性、安定性检测。

## 4. 运行

```bat
cd /d <项目目录>
python app.py
```

打开：

- 端口二：http://127.0.0.1:7880/
- 端口一：http://127.0.0.1:7880/precision
- 健康检查：http://127.0.0.1:7880/api/health

### 一键检验两个端口

双击 **`双端口一键检验.bat`**：

1. 检查 Python / 依赖；
2. 7880 未启动时自动启动后端；
3. 运行 `scripts/verify_ports.py`：健康检查 + 端口二 识别/预测/推荐 + 端口一精准匹配/批量方案 + 高硫强酸拦截；
4. 优先用 **360 浏览器** 打开两个端口（找不到时回退 Edge/系统默认）；
5. 结果写入 `outputs/verify_ports.json`。

也可以手动：

```bat
python scripts/verify_ports.py
```

### 模型配置（GLM-4.5-Flash）

默认配置在项目根目录 **`config.json`**（已被 gitignore，不会上传）：

```json
{
  "provider": "zhipu",
  "base_url": "https://open.bigmodel.cn/api/paas/v4",
  "model": "glm-4.5-flash",
  "protocol": "openai",
  "api_key": "你的智谱 API Key"
}
```

也可以不建文件，使用环境变量：

```bat
set GLM_API_KEY=你的Key
set GLM_MODEL=glm-4.5-flash
set GLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
```

端口一右上角「模型配置」也可保存 Key，底层同样写入 `config.json`。未配置时自动走离线 R01~R12 知识库，功能不受影响。

## 7. 已知边界（汇报时主动说）

1. **端口二的“逐石”是逐石输入，不是图像反演化学**：化学默认值来自库内真实行；图像只提供类别 + D/L/G/T/S。
2. **端口二只适用于常规煤矸石域**；高钙/高铁/低硅/高硫样品会被标“域外”或触发风险拦截，不能拿单点误差替代整体 R²。
3. **CaO 仍弱**（R² 0.354），高钙样品、脱硫/石膏路线必须补检；不要用单点误差宣传“模型很准”。
4. **知识库是规则/案例先验**，不是标准强制值；最终方案必须工程验证。
5. **端口一的相似案例**来自 635 库的 kNN，仅作证据链，不代表同一批物料。
6. 图像与化学默认行是**演示配对**，不是同一块样品；详情见 `data/demo_samples_v2.json` 的 `note`。
