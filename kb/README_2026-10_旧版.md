# 工艺知识库说明

`process_kb.json` 是第三步「工艺推荐」的基础知识库，当前 **19 条**，覆盖建材、化工、环保、能源、生态、资源回收六类路径。

- 19 条包括：高铝提取、莫来石/耐火、水泥混合材、烧结砖、轻质陶粒、骨料/充填、低热值燃料、炭质材料、陶瓷/高岭土、分子筛、吸附材料、地聚合物、火山灰质混合材、脱硫剂、石膏回收、石膏板、选铁、土壤改良、高硅产品
- 条目区间参考课题组「煤矸石成分」项目的 **88 条“成分—处理—用途”桥接案例**（Q25–Q75）、GB/T 29162 等标准与常规工艺指标；它们是**案例分布/工程经验**，不是因果阈值
- 每条附 `basis`（机理依据）与 `ref`（标准/文献/案例来源），便于答辩解释“为什么这块石头推荐这条路线”

## 字段约定

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一英文标识，LLM 返回时用它对齐 |
| `name` | 是 | 中文工艺名 |
| `category` | 否 | 建材 / 化工 / 环保 / 能源 / 生态 / 资源回收 |
| `conditions` | 是 | 成分区间，键可用 `SiO2`/`Al2O3`/`Fe2O3`/`CaO`/`MgO`/`TiO2`/`SO3`/`LOI`，值为 `[下限, 上限]`（wt%） |
| `ratios` | 否 | 特征比值区间，键见下 |
| `gate` | 否 | 定义性指标列表；任一门控不命中，整条 ×0.35 |
| `regime` | 否 | 主导特征白名单；不匹配 ×0.55，匹配 +0.05 |
| `physical` | 否 | D/L/G/T/S 档位 → 小分（总上限 0.15） |
| `bias` | 否 | 全局小偏置，用于成熟度/路线优先级（如地聚合物 +0.03） |
| `process` | 是 | 工艺路线，直接展示 |
| `products` | 是 | 目标产品 |
| `basis` | 是 | 机理依据（为什么这些成分/比值适合） |
| `risk` | 是 | 风险提示 |
| `ref` | 否 | 标准/文献/经验来源 |

### 可用比值

| 键 | 含义 | 典型用途 |
|---|---|---|
| `SI_AL` | SiO₂ / Al₂O₃ | 陶粒、地聚合物、陶瓷 |
| `AL_SI` | Al₂O₃ / SiO₂ | 高铝提取、莫来石 |
| `FE_AL` | Fe₂O₃ / Al₂O₃ | 选铁、陶瓷除铁 |
| `CA_SI` | CaO / SiO₂ | 脱硫、石膏、水泥 |
| `FE_SI` | Fe₂O₃ / SiO₂ | 选铁 |
| `SO3_CA` | SO₃ / CaO | 石膏/石膏板 |
| `LOI_ASH` | LOI / (SiO₂+Al₂O₃) | 燃料、炭质材料 |

`regime` 取值：`carbon` / `high_al` / `high_fe` / `calcareous` / `high_si` / `aluminosilicate` / `low_grade`，由 `dominant_regime()` 按主量成分判定。

## 匹配逻辑

1. **成分区间**：`conditions` 命中得分，偏离按距离衰减（最低 0）。
2. **比值门控**：`ratios` 同法计分；`gate` 中任一指标不命中，整条 ×0.35。
3. **主导特征**：`regime` 不匹配 ×0.55；匹配 +0.05。
4. **物性偏好**：第一步 D/L/G/T/S 档位对应 `physical` 加分，总上限 0.15，只调排序、不推断成分。
5. **置信度**：基础分 ≥0.75 高、≥0.50 中，否则低；只取 ≥0.55 的前 3 条，不足时用 ≥0.30 补齐。
6. **在线模式**：把全部条目（id/name/conditions/ratios/regime/process/basis/risk）塞进 prompt，并要求每块矸石的成分、比值、主导特征、物性一并传入。

## 注意

- 区间是**工程经验值**，不是强制标准；答辩/落地前应做小试/中试 + 重金属/放射性/安定性检测。
- 新增条目后无需重启：每次推荐都会重新读取本文件。
- 若在线模型返回的 `kb_id` 不在库中，后端会保留模型给的名字，但工艺路线/风险会缺失 —— 建议在 prompt 里约束后仍人工核对。
