# 工艺知识库说明

`process_kb.json` 是第三步「工艺推荐」的基础知识库，当前 **16 条**，覆盖建材、化工、环保、能源、生态、资源回收六类路径。

- 原有 10 条：水泥/烧结砖、高铝提铝、耐火、陶瓷/高岭土、脱硫、选铁、骨料/充填、低热值燃料、土壤改良、分子筛
- 本轮新增 6 条：火山灰质混合材、地聚合物/碱激发、吸附材料/水处理、炭质矸石/活性炭前驱体、高硅原料/白炭黑、石膏回收
- 新增条目的区间参考课题组「煤矸石成分」项目的 **88 条“成分—处理—用途”桥接案例**（Q25–Q75）与常规工艺指标；它们是**案例分布**，不是因果阈值

## 文件结构

```json
{
  "version": "2026-10-22",
  "note": "免责声明",
  "entries": [
    {
      "id": "cement_mix",
      "name": "水泥混合材 / 烧结砖原料",
      "category": "建材",
      "conditions": {"SiO2": [40, 72], "Al2O3": [10, 32], "Fe2O3": [0, 12], "CaO": [0, 12], "LOI": [0, 30]},
      "process": "工艺路线（一段话）",
      "products": "目标产品",
      "reason": "一般性判断理由",
      "risk": "落地风险",
      "ref": "方向性依据"
    }
  ]
}
```

## 字段约定

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一英文标识，LLM 返回时用它对齐 |
| `name` | 是 | 中文工艺名 |
| `category` | 是 | 建材 / 化工 / 环保 / 能源 / 生态 / 资源回收 / 能源/材料 |
| `conditions` | 是 | 适用区间，键只能是 `SiO2` / `Al2O3` / `Fe2O3` / `CaO` / `LOI`，值为 `[下限, 上限]`（wt%） |
| `process` | 是 | 工艺路线，会直接展示给用户 |
| `products` | 是 | 产品 |
| `reason` | 是 | 离线模式的兜底理由（在线模式由模型结合具体数值写） |
| `risk` | 是 | 风险提示 |
| `ref` | 否 | 标准/文献/经验来源 |

## 匹配逻辑

1. **离线模式**：对每条工艺，逐指标判断预测值是否落在区间内，命中得 1 分、偏离按距离衰减。
   - **首条件门控**：`conditions` 里的第一个键视为该工艺的定义性指标（如高铝提取看 `Al2O3`、脱硫看 `CaO`、燃料看 `LOI`）。首条件不命中，整条得分 ×0.35，避免只靠 Fe/Ca 宽区间“蹭分”。**新增条目时请把最关键的指标写在第一位。**
   - **高 LOI 修正**：LOI > 20% 时，水泥/烧结砖 −0.12，低热值燃料再 +0.08（高烧失量物料做建材需额外配料）。
   - 再叠加少量**工艺可行性**加权（仅用物理特征，不推断成分）：
     - 大块 D4 → 骨料/充填 +0.12；D3 → +0.08
     - 细小 D1/D2 → 烧结砖 +0.04
     - 纹理细腻 T1 → 陶瓷/高岭土 +0.05
     - LOI > 12 → 燃烧/发电 +0.04（> 20 时 +0.08）
2. **在线模式**：把全部条目（id、name、conditions、process、risk）作为候选塞进 prompt，要求 GLM 只从中选择，并引用具体成分数值；物理特征只允许用于可行性排序。

## 注意

- 区间是**工程经验值**，不是强制标准；答辩/落地前应做小试/中试。
- 新增条目后无需重启：每次推荐都会重新读取本文件。
- 若在线模型返回的 `kb_id` 不在库中，后端会保留模型给的名字，但工艺路线/风险会缺失 —— 建议在 prompt 里约束后仍人工核对。
