# 工艺知识库 v3（R01~R12）

`process_kb_v3.json` 是平台当前知识库，来源于《煤矸石智能匹配平台_数据库与知识库全量有机融合总表.xlsx》的 `02_知识库路线规则与处理工序字典表`，并在工程侧补充了风险门控和可执行的八工序参数。

## 路线

| 编码 | 路线 | 核心准入基因 |
|---|---|---|
| R01 | 破碎筛分级配直用（免煅烧骨料/路基/充填） | 硬质低炭；压碎指标<25%、吸水率<8% |
| R02 | 粉磨+钙质/石膏协同胶结（常温胶凝/膏体充填） | 硅铝质黏土型；矿渣/石膏激发 C-S-H/AFt |
| R03 | 常温粉磨+强碱/水玻璃激发（常温地聚物） | 超细 D50<15μm；Si/Al 1.8~3.5 |
| R04 | 中温煅烧脱羟基（550~900℃）+粉磨（火山灰混合材） | 高岭石≥30%；28d 活性≥80% |
| R05 | 中温煅烧/微波热活化+碱激发（高强地质聚合物） | 高岭石≥40%；碱激发+热养护 |
| R06 | 高温固相烧结/发泡（1050~1400℃制陶粒/砖/陶瓷） | 助熔相（CaO+Fe₂O₃+K₂O）>10%；残碳内燃 |
| R07 | 煅烧/焙烧活化+酸浸提取（提铝/锂镓/白炭黑） | Al₂O₃≥25%、Al/Si≥0.5 |
| R08 | 热活化/酸除杂+碱熔/水热晶化（合成沸石分子筛） | Si/Al 1.5~3.2；低铁 |
| R09 | 超细粉磨+有机/偶联剂/负载改性（功能吸附催化） | 孔结构可调；低铁/可除杂 |
| R10 | 破碎粉磨+多固废/有机质/菌剂协同（生态植生土） | 低毒；St≤1.5%；重金属 I 类 |
| R11 | 化学/CO₂碳化矿化养护（固碳建材/低碳回填） | CaO≥3% 或配富钙固废；CO₂ 反应釜 |
| R12 | 破碎粉磨+燃煤/生物质耦合掺烧（发电与热能回收） | Qnet,ar≥4.18 MJ/kg；配套脱硫/除尘 |

## 匹配逻辑

1. **成分区间**：`conditions` 命中得分，偏离按距离衰减。
2. **特征比值**：`ratios` 权重 1.2；覆盖 Si/Al、Al/Si、Fe/Al、Ca/Si、LOI/灰分、FLUX、FC/LOI。
3. **定义性门控**：`gate` 任一项不命中，整条 ×0.30。
4. **主导特征**：`regime` 不匹配 ×0.60；匹配 +0.04。
5. **物性偏好**：D/L/G/T/S 档位小分，总上限 0.12。
6. **风险规则**：先执行 `risk_rules`；高硫/高钙/重金属/放射性可一票否决或降权；脱硫/细磨勾选可解除对应拦截但保留补检。
7. **决策偏好**：成本 → R01/R02/R12；低碳 → R11/R03/R04；高值 → R07/R08/R09；高强度 → R02/R05/R06。
8. **指定路线**：优先展示，但若被风险拦截会给出提示，不强行推荐。

## 风险规则（8 条）

- 高硫强酸性：St>1.5%，R01/R10 否决，其余需脱硫路线降权；
- 石灰爆裂：CaO>2.5%，未细磨时 R06 否决；
- 高热值/低热值：Qnet 门槛控制 R12；
- SO₃>3.5%：R02 拦截/复核；
- pH<4：R01/R10 拦截；
- 重金属 II 类/超标：R01/R10 拦截；
- 放射性超标：建材路线拦截。

> 阈值是工程经验/标准方向值，不是强制标准；落地必须小试/中试与环保检测。
